# Documentarian

Documentarian turns appliance names, machine models, component families, and
other subjects into organized documentation workspaces inside Home Assistant.
It helps you find the right source material, understand it, and keep the
results available for future work.

## Product features

- **Documentation discovery:** Find user manuals, installation guides,
  maintenance instructions, parts references, and documentation for shared
  components or subassemblies.
- **Organized documentation sets:** Keep the sources for each appliance,
  machine, component family, or subject together in a persistent library.
- **Search and source browsing:** Search across saved documentation and open the
  most relevant documents, pages, and sections.
- **Grounded questions and answers:** Ask installation, maintenance, parts,
  consumables, and troubleshooting questions with references back to the
  supporting source material.
- **Information packages:** Prepare and save useful deliverables such as
  maintenance schedules, installation checklists, consumables lists,
  replacement-part cross-references, and diagnostic summaries.
- **Web research for missing information:** Fill gaps when the saved library is
  incomplete while keeping web-based findings distinct from claims supported
  by saved documentation.
- **Continuing workspaces:** Return to saved conversations, documentation sets,
  and information packages as a project develops.
- **Home Assistant access:** Use the Documentarian workspace from Home
  Assistant and optionally make selected Home Assistant capabilities available
  to the assistant.
